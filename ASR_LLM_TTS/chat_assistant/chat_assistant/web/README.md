# Web 日志浏览器更新记录

## 2026-08-26：软链接日志实时显示

### 更新内容

- 日志目录中的有效文件软链接可以直接在浏览器中读取，不再限定软链接名称。
- `asr_llm_tts` 和日志目录中的软链接文件会被标记为“实时”日志。
- 点击任意实时日志后，前端每秒增量读取新增内容并自动滚动到底部。
- 实时日志窗口标题会动态显示当前日志文件名。
- 点击普通文件时仍按历史日志方式一次性加载，并停止实时轮询。

### 使用示例

在日志目录中创建文件软链接：

```bash
ln -s /path/to/external/application.log /path/to/ASR_LLM_TTS/logs/application_log
```

重启 Web 服务并刷新浏览器后，`application_log` 将出现在日志列表中，并显示“实时”标签。

### 涉及文件

- `web_server.py`：识别和读取日志软链接，并返回 `is_live` 元数据。
- `web_server.js`：支持选择不同实时日志并持续增量轮询。
- `web_server.html`：实时日志标题支持动态更新。

### 安全说明

Web 服务会跟随日志目录中的文件软链接读取目标内容，因此应确保只有可信用户或进程能够在日志目录中创建和修改软链接。
